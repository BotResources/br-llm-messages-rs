# br-llm-messages

Provider-neutral Rust model of an LLM conversation: messages, content blocks,
thinking replay, tool calls and results.

**Status: scaffold.** Version `0.0.0` holds the repository skeleton — manifest,
CI, governance — and no model code. No tag has shipped yet.

## Depending on it

Not published on crates.io: the git tag is the release. Once a `v{version}` tag
exists, pin it with the matching `version` beside it — a tag-only git dependency
carries a `*` version requirement, which `cargo-deny`'s `wildcards = "deny"`
rejects.

```toml
[dependencies]
br-llm-messages = { git = "https://github.com/BotResources/br-llm-messages-rs", package = "br-llm-messages", tag = "vX.Y.Z", version = "X.Y.Z" }
```
